 Purpose

This workbook is the consolidated developer reference for the IGA platform. Everything a backend engineer or website developer needs to build the ERPNext system, the Public APIs, and the customer-facing Verify / Submission flows is contained here.

 Reading Order
10
Tabs 00–19 are CORE IMPLEMENTATION MAPS (modules, workflow, validation, APIs, sprints). Tabs 20+ are DETAILED DOCTYPE / FIELD SPECIFICATIONS — one sheet per DocType, listing every field with type, mandatory flag, source, and notes. 12
 Conventions
13
• Field names use snake_case (e.g., certificate_number, item_status).
• Status / Select values are written exactly as they should appear in ERPNext dropdowns.
• 'Singleton' DocTypes are settings-style — only one record exists.
• 'Mandatory' = required at save time; 'Read Only' = system-managed, never user-edited.
• All dates are stored as Date or Datetime; all currency values are EGP unless noted.

15
 Scope
16
Phase 1 covers Coins, Medals, and Tokens. Banknotes and Trading Cards are out of scope for Phase 1 but the architecture absorbs them through master data only — no schema redesign.
