 SLAB INVENTORY DEDUCTION
15
HowOn save when slab_status changes to 'Slabbed': create Stock Entry (Material Issue) for Item 'IGA Slab – {slab_size}' qty=1 from default warehouse. Use frappe.get_doc('Stock Entry').
16
IGA Slab MasterCreate Item master records per slab size (Standard, Oversize, Multi Insert). These are physical inventory items tracked in ERPNext stock.
17
RollbackIf slab is rejected (QC Fail → re-slab): create new Stock Entry to deduct again. Do NOT reverse previous deduction.

 LABEL PREVIEW (HTML Field)
19
ImplementationClient Script (JS): on every label_* field change, build HTML string mimicking left-panel / right-panel layout. Set frm.set_value('label_preview', html_string).
20
HTML structureTwo-column div: left=text block, right=grade+designation. Bottom: cert number. Use inline CSS only (no external).
21
Font sizesMatch physical label proportions: Country/Denom large (18–20px), Year medium (14px), Series/Name small (11px), Grade very large (28–32px bold).
